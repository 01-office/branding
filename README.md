# @01.works/branding

Shared branding utilities for 01.works.

## Installation

```sh
npm install @01.works/branding
```

## Usage

```ts
import { showBranding } from "@01.works/branding";

showBranding();
```

The package scaffold is ready for publishing, but the `showBranding`
implementation comes next and is not included yet.

## Development

```sh
npm test
npm run typecheck
npm pack --dry-run
```
