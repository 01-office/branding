# @01.works/branding

Shared branding utilities for 01.works.

## Installation

```sh
npm install @01.works/branding
```

## Usage

```ts
import { showBranding } from "@01.works/branding";

showBranding();
```

This repository is only a package scaffold. It is not publishable yet because
the exported `showBranding` implementation does not exist. Implementation and
tests come next.

## Development

```sh
npm test
npm run typecheck
npm pack --dry-run
```
